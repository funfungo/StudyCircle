# 添加 Vite 编译流程

- **时间**: 2026-03-20 11:04
- **对话 ID**: `7e654735-26ff-487e-aa7f-9eac415b8876`

## 需求

为原始纯静态 HTML 项目添加 Vite 构建工具链。

## 过程

1. 创建 `package.json`，添加 Vite 依赖和 dev/build/preview 脚本
2. 创建 `vite.config.js`，设置 `root: 'src'`，构建输出到 `dist/`
3. 将 `src/llm-study-group.html` 重命名为 `src/index.html`
4. 将内联 CSS 提取到 `src/style.css`，创建 `src/main.js` 作为 JS 入口
5. 将 `assets/` 移至 `public/`（Vite 静态资源约定）
6. 创建 `.gitignore`
7. 修复 CSS 加载延迟导致的 FOUC（闪烁）：将 CSS 从 JS import 改为 HTML `<link>` 直引
8. 将 Google Fonts 下载到本地：使用 `@fontsource` npm 包自托管字体
9. 创建 `.cursor/rules/use-pnpm.mdc` 规则，统一使用 pnpm 管理依赖

## 项目结构变化

```
StudyCircle/
├── package.json
├── vite.config.js
├── .gitignore
├── public/          ← 原 assets/
├── src/
│   ├── index.html   ← 原 llm-study-group.html
│   ├── style.css    ← 从 HTML 提取的样式
│   └── main.js      ← JS 入口，导入字体
└── node_modules/
```
