# 抽离设计系统 & 换肤功能

- **时间**: 2026-03-20 11:37
- **对话 ID**: `dd7107d7-cc68-40f3-ac62-a4b3b900ba6d`

## 需求

1. 将页面的散落样式值系统化为 Design Tokens
2. 添加多主题换肤功能
3. 将配色方案改为配置文件驱动

## 过程

### Phase 1: 设计令牌（Design Tokens）

创建 `src/design-tokens.css`，包含 9 大类令牌：
- Colors（13 个）、Font Stacks（3 个）、Font Sizes（17 个）
- Font Weights（4 个）、Line Heights（7 个）、Letter Spacings（6 个）
- Spacing（18 个，4px 基准网格）
- Borders / Shadows（6 个）、Transitions / Layout（6 个）

重构 `style.css`，所有硬编码值替换为 `var(--token)` 引用。

### Phase 2: 三主题换肤

| 主题 | 代号 | 风格 |
|------|------|------|
| Warm | `warm` | 暖纸质感（默认） |
| Dark | `dark` | 暖调深色夜读 |
| Ocean | `ocean` | 冷调蓝灰学术 |

实现要点：
- 颜色分两层：基础色（随主题变）+ Chrome 语义色（始终深色的顶栏/页脚）
- `<head>` 内联脚本防止主题闪烁
- 顶栏圆形按钮循环切换主题
- `localStorage` 持久化 + 系统偏好自动检测

### Phase 3: 配色配置文件

创建 `src/themes.json`，将所有主题颜色（21 个令牌/主题）集中管理。
JS 动态读取配置并注入 CSS 自定义属性，CSS 中移除硬编码的主题色块。

## 产出

- `src/design-tokens.css` — 设计令牌系统
- `src/themes.json` — 主题配色配置文件
- 主题切换 UI + 持久化逻辑
