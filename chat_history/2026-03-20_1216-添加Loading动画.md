# 添加 Loading 动画

- **时间**: 2026-03-20 12:16
- **对话 ID**: `d8751280-1676-4a2b-a60f-3655a99c3693`

## 需求

网络加载时因资源加载顺序不同导致页面抖动，需要一个 loading 遮罩等资源加载完成后再显示内容。

## 实现方案

### Loading 遮罩（index.html）
- 在 `<body>` 顶部添加全屏遮罩层
- 使用内联 `<style>` 确保样式在外部资源加载前就生效
- 背景色跟随当前主题（通过 CSS 变量 `--color-paper`）
- 一条橙色滑块扫过的进度指示条动画
- 初始版本有 "LLM" 脉冲文字，应用户要求简化为仅保留进度条

### 退场逻辑（App.jsx）
- React 挂载后等待 `document.fonts.ready`（字体加载完成）
- 给 `body` 添加 `app-ready` 类 → 触发内容入场动画
- 给遮罩添加 `loaded` 类 → 0.5s 淡出过渡
- 过渡结束后移除 loading DOM 元素

### 入场动画（style.css）
- 各区块默认 `opacity: 0`
- `fadeUp` 动画仅在 `.app-ready` 类存在时生效
- 各模块依次浮入（staggered delay）

## 效果流程

打开页面 → 显示 loading 进度条 → 字体和 React 就绪 → loading 淡出 → 页面各模块依次 fadeUp 入场
