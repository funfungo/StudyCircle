# PNG 转 SVG

- **时间**: 2026-03-20 11:57
- **对话 ID**: `2175eb50-7f71-45a1-a692-307e80157857`

## 需求

将 `public/logo-white.png` 转换为 SVG 格式，并提供不同线条粗细的版本。

## 过程

1. 使用 `potrace` 工具进行位图到矢量转换
2. Python Pillow 预处理图片，提取白色线条轮廓
3. 生成的 SVG 填充色设为 `#ffffff`，尺寸 1024x1024
4. 用户要求线条更细，通过形态学腐蚀（erosion）预处理后重新转换

## 产出

- `logo-white.svg` — 原始粗细（用户删除了）
- `logo-white-thin1.svg`（38KB）— 线条减细约 1px
- `logo-white-thin2.svg`（9KB）— 线条减细约 2px

## 备注

thin2 版本文件显著更小，说明部分细节在腐蚀过程中丢失。
