# 移动端 3:4 翻页版本

- **时间**: 2026-03-21 09:30
- **对话 ID**: `b6c5cf47-4f30-4cc4-80a2-cd3d63f23bfd`

## 需求

提供一个移动端翻页版本，每页严格 3:4 宽高比，将现有模块重新组合分页展示，并支持逐页截图导出。

## 过程

1. **创建翻页容器 `MobileSwiper`** — 支持触摸滑动、鼠标滚轮（带节流）、键盘方向键，右侧圆点导航 + 底部页码
2. **创建 `MobileStudyCirclePage`** — 将原有 9 个组件重新编排为 6 页：
   - Page 1: TopBar + Hero + StatsStrip
   - Page 2: BookSection
   - Page 3: Schedule Week 01–04
   - Page 4: Schedule Week 05–08
   - Page 5: FormatSection + Perks（暗色背景）
   - Page 6: CTA + Footer
3. **修复翻页跳页 bug** — wheel 事件的 effect 依赖 `current` 导致每次翻页重新绑定 listener，`wheelLock` 被重置失效。改用 `useRef` 保存当前页码和锁定状态，effect 只绑定一次
4. **扩展 screenshot 脚本** — 新增 `screenshot:pages` 模式，用 414×552 viewport（3:4）打开 `?view=mobile`，逐页对 `.mobile-page` 元素截图，输出到 `exports/{themeId}/`
5. **调整导出尺寸** — 将 pages 模式的 viewport 从 1080×1440 改为 414×552，与移动端模拟宽度一致

## 产出

- `src/components/MobileSwiper.jsx` + `MobileSwiper.css` — 翻页容器组件
- `src/components/MobileStudyCirclePage.jsx` + `MobileStudyCirclePage.css` — 移动端分页页面
- `src/App.jsx` — 新增 `?view=mobile` URL 参数切换视图
- `scripts/screenshot.mjs` — 新增 `SCREENSHOT_PAGES` 模式
- `package.json` — 新增 `screenshot:pages` 脚本
