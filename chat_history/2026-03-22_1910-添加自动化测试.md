# 添加自动化测试

- **时间**: 2026-03-22 19:10
- **对话 ID**: `N/A`

## 需求

为项目添加自动化测试，最小可用范围，覆盖核心流程（报名表单、管理页登录），使用单元/组件测试。

## 过程

1. 选型：Vitest + React Testing Library + jsdom，与 Vite 原生集成
2. 安装 5 个 devDependencies：vitest、@testing-library/react、@testing-library/jest-dom、@testing-library/user-event、jsdom
3. 在 vite.config.js 添加 test 配置块（environment: jsdom、globals: true、setupFiles）
4. 创建 Supabase 客户端 mock（`src/lib/__mocks__/supabase.js`），导出可控的 mock 函数
5. 编写 RegistrationPage 测试 6 个用例：契约显示、接受契约、按钮禁用、成功提交、失败提示、提交中状态
6. 编写 AdminPage 测试 4 个用例：登录表单、登录失败、数据列表、空数据提示
7. 全部 10 个用例一次通过

## 产出

- 修改：`vite.config.js`（添加 test 配置）、`package.json`（添加 test/test:watch 脚本 + devDependencies）
- 新增：`src/test/setup.js`、`src/lib/__mocks__/supabase.js`、`src/components/__tests__/RegistrationPage.test.jsx`、`src/components/__tests__/AdminPage.test.jsx`
