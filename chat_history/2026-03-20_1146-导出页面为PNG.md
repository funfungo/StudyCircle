# 导出页面为 PNG

- **时间**: 2026-03-20 11:46
- **对话 ID**: `0a54482e-becf-4900-bc2f-e298b6a5af00`

## 需求

实现一键将页面保存为 PNG 图片的功能。

## 过程

### 尝试 1: html2canvas（失败）

在页面内嵌导出按钮，使用 `html2canvas` 截图。问题：html2canvas 不支持 CSS 自定义属性（`var()`），导致大部分内容渲染为黑色。

### 尝试 2: html-to-image（部分成功）

切换到 `html-to-image`（基于浏览器原生 SVG foreignObject），CSS 变量可正确解析。用户回退了此方案。

### 尝试 3: html2canvas + 内联计算样式（布局错乱）

通过 `onclone` 回调将所有元素的 `getComputedStyle()` 计算值内联到克隆 DOM。
问题：内联了 `width`/`height` 后破坏了 CSS grid/flex 布局。

### 最终方案: Playwright 无头浏览器截图

用户要求独立于页面的截图脚本。使用 Playwright 启动 Vite dev server + 无头 Chromium：
- 利用浏览器原生渲染，CSS 变量、grid 布局、字体全部完美支持
- 支持指定主题和一次导出所有主题
- 2x 分辨率输出

## 产出

- `scripts/screenshot.mjs` — Playwright 截图脚本
- `pnpm screenshot [theme]` / `pnpm screenshot --all` 命令
- 移除了页面内的导出按钮和 html2canvas 依赖

## 关键经验

- html2canvas 不支持 CSS 自定义属性，对现代 CSS 特性（grid、clamp 等）支持差
- 内联计算样式时不能包含布局属性（width/height），否则会破坏 flex/grid
- 浏览器原生渲染（Playwright/Puppeteer）是最可靠的截图方案
