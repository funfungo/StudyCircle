# 去除图片白色背景

- **时间**: 2026-03-20 10:53
- **对话 ID**: `877f71f3-d4ea-4dd3-a113-089f754ca1b4`

## 需求

将 `assets/image.png`（学习小组插图）中残留的白色背景去除，生成纯净的透明背景 PNG。

## 过程

1. 使用 Python Pillow 处理图片，通过亮度阈值区分背景与线条
2. 首次处理后线条变得过于半透明，经过多轮阈值调优，最终达到：
   - 88.7% 像素完全透明（背景）
   - 10.8% 像素完全不透明（线条）
   - 0.5% 像素半透明（抗锯齿边缘）
3. 应用户要求生成了白色线条的反色版本 `image-white.png`
4. 再从白色版本反色回黑色版本 `image-black.png`，发现锯齿问题
5. 最终采用「统一 RGB + 仅保留 alpha 通道」的方式修复了锯齿
6. 用户要求回退到 RGB 反色版本，已执行回退

## 产出

- `assets/image.png` — 黑色线条 + 透明背景（已优化）
- `assets/image-white.png` — 白色线条 + 透明背景
- `assets/image-black.png` — 从白色反色回的黑色线条版本

## 关键经验

- 对抗锯齿像素的处理需要精细的阈值控制
- 反复反色会导致灰色过渡像素变成可见锯齿，更好的做法是统一 RGB 仅用 alpha 通道控制透明度
