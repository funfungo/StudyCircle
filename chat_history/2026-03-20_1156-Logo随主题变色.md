# Logo 随主题变色

- **时间**: 2026-03-20 11:56
- **对话 ID**: `2431716c-92ed-4bd5-a9b9-7b867ddabfc1`

## 需求

Hero 区域的 SVG Logo 应该随主题切换自动变色。

## 问题

Logo 是通过 `<img>` 标签引入的 SVG 文件，SVG 内部 `fill` 写死为 `#ffffff`。`<img>` 标签无法通过 CSS 修改内部 SVG 的填充色。

## 解决方案

使用 CSS `mask-image` 技术：

1. 将 `<img>` 替换为 `<div role="img">`
2. 用 SVG 文件作为 `mask-image` 遮罩形状
3. 用 `background: var(--color-ink)` 作为填充色，自动跟随主题

## 效果

- Warm 主题：深色（`#0f0e0c`）
- Dark 主题：浅色（`#e0dcd4`）
- Ocean 主题：深蓝色（`#1e293b`）

切换主题时有平滑过渡动画。
