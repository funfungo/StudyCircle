# 改为 React 编译

- **时间**: 2026-03-20 11:49
- **对话 ID**: `988ed8d8-e1a3-43b0-a81f-e525a52f68ef`

## 需求

将项目从原生 HTML/JS 改造为 React 项目，页面各部分拆分为独立组件。

## 过程

1. 安装 React 依赖：`react`、`react-dom`、`@vitejs/plugin-react`
2. 更新 `vite.config.js` 添加 React 插件
3. 创建组件目录 `src/components/` 和 hooks 目录 `src/hooks/`
4. 拆分 9 个页面组件
5. 将主题逻辑抽取为 `useTheme` hook
6. 创建 `App.jsx` 组合所有组件，`main.jsx` 作为入口
7. 更新 `index.html` 为 React 挂载点
8. 删除旧的 `main.js`

## 组件结构

```
src/
├── main.jsx            ← React 入口
├── App.jsx             ← 主组件
├── hooks/
│   └── useTheme.js     ← 主题切换逻辑
└── components/
    ├── TopBar.jsx       ← 顶栏 + 主题切换按钮
    ├── Hero.jsx         ← 主视觉区
    ├── StatsStrip.jsx   ← 数据统计条
    ├── BookSection.jsx  ← 书目介绍
    ├── Schedule.jsx     ← 四周计划
    ├── FormatSection.jsx← 学习形式
    ├── Perks.jsx        ← 为什么要一起读
    ├── CTA.jsx          ← 行动号召
    └── Footer.jsx       ← 页脚
```
