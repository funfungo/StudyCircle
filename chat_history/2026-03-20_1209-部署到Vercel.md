# 部署到 Vercel

- **时间**: 2026-03-20 12:09
- **对话 ID**: `942a8ad9-84fb-46a8-968a-813be416a571`

## 需求

将页面部署为在线可访问的网页，低成本且便捷。

## 方案对比

| 方案 | 费用 | 特点 |
|------|------|------|
| Vercel | 免费 | 1 条命令部署，自动 HTTPS |
| Netlify | 免费 | 可拖拽 dist 上传 |
| GitHub Pages | 免费 | 需先建 GitHub 仓库 |
| Cloudflare Pages | 免费 | CDN 全球加速 |

## 过程

1. 安装 Vercel CLI：`pnpm add -g vercel`
2. 登录 Vercel：`vercel login`
3. 部署：`vercel`（项目名自动转小写为 `study-circle`）
4. 添加 `pnpm deploy` 命令：`vite build && vercel --prod`

## 产出

- 上线地址：**https://study-circle-five.vercel.app**
- `pnpm deploy` 一键构建 + 部署

## 补充讨论

- Vercel 在中国大陆访问不稳定，`.vercel.app` 域名可能被墙
- 国内受众推荐 Cloudflare Pages（无需备案，有香港节点）
- Vercel 免费版（Hobby）限制：100GB 带宽/月，仅限个人非商业项目
