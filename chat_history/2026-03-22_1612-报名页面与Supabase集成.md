# 报名页面与 Supabase 集成

- **时间**: 2026-03-22 16:12
- **对话 ID**: `f75aaec1-e654-44c1-b7d8-face3559b91a`

## 需求

创建一个报名页面，接入 Supabase 登记表单数据，并使用 React Router 管理路由。

## 过程

1. **安装依赖**：添加 `@supabase/supabase-js` 和 `react-router-dom`
2. **Supabase 客户端**：创建 `src/lib/supabase.js`，采用惰性初始化避免缺少环境变量时崩溃
3. **报名页面**：创建 `RegistrationPage` 组件，包含姓名、微信号、小红书号、邮箱、Python 基础（单选）、参加动机、其他补充共 7 个字段
4. **路由重构**：从 query param（`?view=register`）切换到 React Router（`/register`），在 `main.jsx` 包裹 `BrowserRouter`，`App.jsx` 使用 `Routes`/`Route`
5. **导航更新**：CTA 按钮改用 `<Link to="/register">`，报名页返回按钮改用 `<Link to="/">`，移动端 CTA 同步更新
6. **DevTools 扩展**：在开发工具面板中加入 Route 导航区，可快速切换首页/报名页
7. **部署配置**：新增 `vercel.json` 配置 SPA rewrites

ALTER TABLE registrations ENABLE ROW LEVEL SECURITY;
